# there are three main types of learnings 

## Supervised learning

	• How it works: The model is trained on a labeled dataset, meaning every input comes with the correct answer or target output. The algorithm learns the relationship between the input and the label to make predictions on new, unseen data.
	• Common tasks: Classification (e.g., spam vs. not spam) and Regression (e.g., predicting house prices).
	• Examples: Image recognition, credit card fraud detection.

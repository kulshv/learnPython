# Intent

## Goal

Create an AI-powered PDF question-answering bot with a conversational chatbot interface. The main user experience is a chat where users enter questions and receive answers grounded in their PDF files.

## Objectives

- Accept and process PDF documents as the source material for answers.
- Provide a chatbot-style interface where users can enter questions and receive answers in a conversation.
- Ground answers in the PDF content and show supporting source references when available.
- Provide a way to upload or select PDFs to use as the chatbot's knowledge source.
- Evaluate answer quality and present the evaluation results.

## Scope

Plan the document ingestion, question-answering, user interface, and evaluation workflow. Select implementation details such as frameworks, model providers, storage, and evaluation metrics during planning.

## Success Criteria

- A user can provide a PDF, enter questions in the chatbot interface, and receive conversational answers about its contents.
- Answers are relevant to the document and can be traced to supporting PDF content.
- The evaluation process produces clear, repeatable results for answer quality.
